AI4Human In development

A multi-agent wellness companion that puts safety first.

Staying healthy is confusing: food, workouts, sleep and mood live in different apps, advice is generic, and chatbots can give unsafe numbers. AI4Human is one chat window with a team of AI specialists for nutrition, fitness, sleep and recovery, and mental wellbeing. An orchestrator brings in the right ones and gives one clear answer, while safety is enforced in code, not left to prompts.

How it works

  1. You ask a question, such as "help me plan a week of meals".
  2. A safety gate checks it first. Crisis, medical red-flag and eating-disorder messages get a vetted response straight away, and the AI never runs.
  3. The orchestrator brings in the specialists the question needs. Each has a narrow job and only the tools it needs.
  4. An output gate checks the answer before you see it, and it streams in as it's written.

  • Numbers come from tools

    Calorie and macro targets come from a calculator with a safe floor, never from the model.

  • Safety in code, not prompts

    The output gate blocks targets below the floor, supplement or medication doses, and diagnoses.

  • Locked-down tools

    Tools are allow-listed by a hook. There are no shell or file tools for the agents to reach.

  • Private by design

    Data stays in a local database. The user's own API key lives in the browser tab and is never stored or logged.

Measured safety

Safety is tested, not assumed. Offline evals run on every change and fail the build on a regression: the input gate catches all 27 direct crisis, medical and eating-disorder messages in its test set with no false alarms on 25 everyday ones, and the output gate and calorie floor pass all 15 and 12 of their cases.

The known gaps are written down, not hidden. The input gate is rule-based, so indirect phrasings such as "I don't see the point in going on" still reach the model, which is prompted, but not forced, to handle them. The next step is a second, model-based safety check, measured with the same evals. Live evals of specialist quality are written and run next, against the real model.

Wellness guidance only, not medical advice. Adults 18+.
