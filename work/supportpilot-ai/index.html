SupportPilot AI

Multi-tenant support AI, embedded with one script tag.

A chat assistant any business can drop into its site. It answers from the business's own documents with citations, looks up orders or appointments for the signed-in customer only, files Jira tickets and hands off to a live agent. Quality is gated by about 20 release checks before anything ships.

Demo

95 seconds, no audio, a caption on each step. A fictional Sydney hospital website on the left, the SupportPilot agent console on the right.

  1. A guest asks about parking. The answer comes only from the hospital's own documents and cites the source.
  2. The guest asks about an appointment and is asked to sign in first.
  3. Peter, signed in, sees his appointment APT-1001.
  4. Mary asks about the same number and gets "not found", the same reply as for a number that doesn't exist, so nothing leaks.
  5. Mary reports a problem and a Jira ticket is filed.
  6. Peter asks for a person. The handoff skips the model entirely, and the chat lands in Sam's queue in the console.
  7. Sam takes over, they chat live, and Sam resolves the conversation.

Recorded with a keyword stand-in model, so the reply wording is scripted. Sign-in, retrieval, appointment lookups, tickets, handoff and live messaging are the real code paths.

Numbers

  • 153tests passing
  • 94%test coverage
  • ~20release gates, with zero tolerance on security
  • 1script tag to embed it on any site

The release gates are tested by breaking the product on purpose (an IDOR bug, a forged token, missing tenant scoping, a hallucinating model) and requiring the gates to fail.

How it works

  • Grounded answers

    Retrieval over each tenant's own documents, with confidence bands. When nothing relevant comes back, it says so instead of guessing.

  • Authorization in code

    The model never decides who can see what. Lookups are scoped to the signed-in customer, with three separate JWT audiences.

  • Human handoff

    Customers can always reach a person. The agent console has a queue, live chat and resolve.

  • One product, many businesses

    Each tenant configures its own knowledge, tone and record types: retail orders, hospital appointments or bookings.
