Selected work

SupportPilot AI

Multi-tenant customer-support AI. Drop in with one script tag.

A chat assistant any business can embed on its site. It answers from each customer's own documents with source citations and a confidence gate so it does not guess, checks order status for the signed-in user only, opens Jira tickets after confirmation, and hands off to a live human agent in real time.

Security is designed in layers: identity comes from a token signed by the customer's backend, the model cannot choose whose data to read, and a foreign order and a missing order return identical responses. Quality is gated by about 20 release checks with a READY or NOT READY verdict, 137 tests at 93.9% coverage, and a capacity and cost model sized for roughly 30,000 conversations a day.

  • React + Shadow DOM widget
  • BM25 retrieval
  • WebSockets

  • Prometheus
  • Docker Compose

AI4Human

Multi-agent wellness companion. In active development.

An orchestrator coordinates nutrition, fitness, sleep and recovery, and mental-wellbeing specialists plus a check-in agent. Safety is enforced in code, not just prompts: crisis, eating-disorder and medical red-flag messages get a vetted response and the agents never run, tools are allow-listed by a hook, and an output gate blocks unsafe calorie targets, dosing advice and diagnoses. Calorie and trend numbers come from tools, not the model.

It ships with offline safety evals and 52 backend tests, optional Langfuse tracing with content stripped by default, streaming responses, and bring-your-own-key privacy.

  • FastAPI
  • Next.js + TypeScript
  • SSE streaming
  • SQLite
